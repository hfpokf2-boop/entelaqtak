# انطلاقتك — استوديو صُنّاع المحتوى

الموقع المنشور: https://sasa-antilaqatuk.github.io/entelaqtak/

## التشغيل
- واجهة عربية RTL تعمل كصفحة ثابتة على GitHub Pages.
- لا يلزم تسجيل الدخول لاستخدام الأدوات الأساسية.
- تُحفظ المشاريع محليًا في المتصفح الحالي عبر `localStorage`.
- استخدم «الإعدادات والبيانات» لتصدير نسخة JSON أو استيرادها. احتفظ بنسخة خارج الجهاز عند تغيير المتصفح أو الجهاز.

## الذكاء الاصطناعي
- الوضع المحلي التجريبي يعمل دون اتصال بمزود خارجي.
- يمكن اختيار Gemini أو OpenAI أو نقطة نهاية متوافقة من الإعدادات.
- مفتاح API يبقى في ذاكرة الصفحة ولا يُضمّن في النسخ الاحتياطية أو التخزين المحلي بعد التحديث الأمني؛ ستحتاج إلى إدخاله مجددًا بعد إعادة تحميل الصفحة.
- هذا لا يجعل المفتاح سرّيًا على جهاز المستخدم؛ لا تستخدم مفتاحًا مشتركًا أو ذا صلاحيات واسعة. للاستخدام العام، استخدم وسيطًا خلفيًا يحفظ المفتاح كسرّ ويطبق المصادقة وحدود الاستخدام.
- نقاط نهاية OpenAI وGemini المدمجة تتطلب HTTPS والنطاق الرسمي للمزود.

## النشر والصيانة
- النشر يتم عبر GitHub Actions عند تحديث الفرع الرئيسي.
- لا تضع مفاتيح API أو مفاتيح Supabase السرية أو Service Role في ملفات المستودع.
- توجد ملفات Supabase اختيارية في `supabase/`؛ لا يلزم إعدادها لتشغيل الأدوات المحلية.
