# انطلاقتك — مساعد صُنّاع المحتوى

الموقع: https://sasa-antilaqatuk.github.io/entelaqtak/

## التشغيل والبيانات
- واجهة عربية RTL ثابتة تعمل على GitHub Pages دون خادم إلزامي.
- الأدوات الأساسية تعمل محليًا دون تسجيل دخول.
- تحفظ الأعمال في `localStorage` على المتصفح والجهاز الحالي.
- صدّر نسخة JSON بانتظام قبل تغيير الجهاز أو المتصفح.
- إصدار مخطط البيانات v3 مع الحفاظ على خصائص البيانات السابقة وترحيلها بالتطبيع.

## مساحة العمل
- أفكار المحتوى، استوديو الحزم، إعادة التدوير، كاتب السكريبت، العناوين وSEO.
- تقويم النشر، متابعة الأداء اليدوية، وتحدي 30 يوم.
- عقل المحتوى الذكي: ملف صانع المحتوى وتوصيات تستند إلى السجلات المحلية.
- رادار الموضوعات: روابط بحث خارجية؛ لا يعرض ترندات مباشرة أو أرقامًا غير موثقة.
- مصنع الفيديوهات: خطة مشاهد ولقطات قابلة للتعديل والتصدير.
- هوية المحتوى: نبرة العلامة وأسلوبها وما يجب تجنبه.
- مختبر العناوين: حفظ تجارب A/B وتسجيل النتيجة يدويًا.
- أكاديمية انطلاقتك: مسار تعلم ومهام تقدم محلية.

## الذكاء الاصطناعي
- الوضع المحلي التجريبي لا يحتاج اتصالًا بمزود خارجي.
- يمكن ضبط Gemini أو OpenAI من صفحة الإعدادات.
- مفتاح API يبقى في ذاكرة الصفحة ولا يدخل في التخزين المحلي أو النسخ الاحتياطية، لكنه يظل مرئيًا للمستخدم في المتصفح. لا تستخدم مفتاحًا مشتركًا أو ذا صلاحيات واسعة.
- للاستخدام العام الآمن، استخدم وسيطًا خلفيًا يحتفظ بالمفتاح كسرّ ويطبق حدود الاستخدام والمصادقة.
- قد تمنع بعض خدمات المزود الطلبات المباشرة من المتصفح عبر CORS.

## الأمان والصيانة
- لا تضع مفاتيح API أو مفاتيح Supabase السرية أو Service Role في المستودع.
- ملفات Supabase اختيارية وليست مطلوبة لتشغيل مساحة العمل المحلية.
- الاقتراحات والمسودات تحتاج مراجعة الحقائق والمصادر قبل النشر. أرقام الأداء تُدخل يدويًا ولا تُجلب تلقائيًا من المنصات.

## استوديو الصوت (ElevenLabs)
- يحوّل النص العربي إلى ملف MP3 باستخدام نموذج `eleven_multilingual_v2`.
- يتطلب تسجيل الدخول بحساب الموقع، ومفتاح `ELEVENLABS_API_KEY` محفوظًا كـ Supabase Edge Function Secret.
- لا تضع مفتاح ElevenLabs في الواجهة أو GitHub. أضفه من Supabase Dashboard > Edge Functions > Secrets.
- يتطلب المفتاح صلاحية قراءة الأصوات وتوليد الكلام. قد تستهلك كل عملية توليد رصيدًا من خطة ElevenLabs.
- الإصدار الأول لا يتضمن استنساخ الأصوات أو رفع عينات صوتية.
### إعداد مفتاح ElevenLabs
1. أنشئ مفتاح API من إعدادات ElevenLabs مع صلاحية قراءة الأصوات وتحويل النص إلى كلام.
2. افتح [أسرار Supabase للمشروع](https://supabase.com/dashboard/project/dbetanrnhdabuachxdhc/functions/secrets).
3. أضف `ELEVENLABS_API_KEY` في خانة Key والصق المفتاح في Value ثم احفظ.
4. أعد فتح استوديو الصوت وسجّل الدخول، ثم حمّل الأصوات وجرّب نصًا قصيرًا.
