# انطلاقتك — استوديو صُنّاع المحتوى

موقع عربي RTL ثابت، جاهز للنشر على GitHub Pages.

## الملفات
- `index.html`: الموقع والأدوات (CSS وJavaScript مضمّنان).
- `favicon.svg`: أيقونة المتصفح.
- `.nojekyll`: تعطيل معالجة Jekyll الافتراضية.

## تفعيل النشر
1. افتح المستودع: https://github.com/hfpokf2-boop/entelaqtak
2. اختر **Settings → Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح:
   https://hfpokf2-boop.github.io/entelaqtak/

## الخصائص
- مولّد أفكار لمجالات ومنصات متعددة.
- استوديو حزمة المحتوى (فكرة وخطاف وعناوين وسكريبت ووصف وهاشتاجات وقائمة تصوير).
- كاتب سكريبت، واقتراح عناوين وأفكار صور مصغرة.
- مساعد صياغة SEO.
- تقويم نشر وتصدير CSV.
- متابعة أداء يدوية وحساب معدل التفاعل.
- تحدي 30 يوم.
- تصدير واستيراد نسخة احتياطية JSON.

## تنبيه تقني
هذا إصدار Front-end فقط. البيانات تُحفظ محليًا في المتصفح باستخدام localStorage، ولا تتم مزامنتها بين الأجهزة. المولدات تعتمد على قوالب محلية وليست متصلة حاليًا بخدمة ذكاء اصطناعي أو API أو إحصائيات مباشرة من المنصات. لا تدخل كلمات مرور أو بيانات حساسة.
