# انطلاقتك — استوديو صُنّاع المحتوى

موقع عربي RTL ثابت يعمل على GitHub Pages.

## المزايا
- مولّد أفكار لمجالات ومنصات متعددة.
- استوديو حزمة المحتوى.
- إعادة تدوير المحتوى إلى Shorts / Reels / TikTok / منشورات / بودكاست.
- كاتب سكريبت، وعناوين وصورة مصغرة.
- مساعد صياغة SEO.
- تقويم نشر وتصدير CSV.
- متابعة أداء يدوية.
- تحدي 30 يوم.
- استيراد وتصدير نسخة احتياطية.

## النشر
النشر تلقائي عبر GitHub Actions عند كل تحديث على فرع main.
الرابط: https://hfpokf2-boop.github.io/entelaqtak/

## التخزين والذكاء الاصطناعي
الإصدار المنشور حاليًا Front-end ثابت. تُحفظ البيانات محليًا على الجهاز عبر localStorage، ومخرجات المولدات الحالية قوالب محلية وليست اتصالًا حقيقيًا بخدمة ذكاء اصطناعي.
المرحلة التالية تستخدم Supabase Auth وPostgres مع سياسات RLS، وEdge Function للاتصال بمزود الذكاء الاصطناعي بمفتاح محفوظ على الخادم. لا يوضع أي مفتاح سري في ملفات الموقع العامة.
